## Something new you picked up, in class or anywhere else

- A key in a Vercel environment variable is read inside the function as `process.env.OPENROUTER_API_KEY`. It isn't in any repo file and never reaches the browser, which is why the browser has to go through my own `/api/ask` instead of calling OpenRouter directly.
- CORS is enforced by the browser, not the server. I can see whether a server allows my page in Network > Response Headers, under `access-control-allow-origin`.
- Read the level before the field: `data` is the whole response, and the actual list is often one level down, like `data.data`.
- GET puts its data in the URL, and POST puts it in the body (Network > Payload).
- The API has no memory. A chat app has to send all the earlier messages again every turn, and the instructions get sent with every prompt too, so they cost input tokens each time ("hi" was 5 tokens, but 90 with the instructions).
