## Something new you picked up, in class or anywhere else

- `await response.json()` turns the response text into a JavaScript object, and `await` only works inside an `async` function. `console.log(data)` first, then decide what to put on the page.
- GET reads data and POST sends it. The message board POST needed `method: "POST"`, a JSON body, and an `X-Token` header.
- Breaking the professor's site showed why the `textContent` rule from week 7 matters: the board escaped `<` and `>` but not double quotes, so someone could break out of an attribute. The fix was to build the rows with DOM elements and `textContent`. Anything from a user or an API should never go in through `innerHTML`.
- Loading saved data safely: `JSON.parse(localStorage.getItem(KEY) || '[]')` inside `try`/`catch`, and `Array.isArray` to check it's really a list.
- If an MP3 needs an API key, it can't go on GitHub Pages, because anyone could read the key in the page files. It has to go on Vercel instead (we learn this Tue 11/03).
